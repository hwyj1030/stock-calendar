# 실적 캘린더

삼성전자와 SK하이닉스의 분기 실적 발표 일정을 표시하는 정적 웹사이트입니다. `index.html` 하나로 동작하므로 별도 빌드 도구나 서버가 필요하지 않습니다.

## GitHub Pages 배포

1. 이 파일과 `index.html`을 GitHub 저장소의 기본 브랜치에 올립니다.
2. 저장소에서 **Settings → Pages**를 엽니다.
3. **Build and deployment**에서 `Deploy from a branch`를 선택합니다.
4. 기본 브랜치와 `/ (root)` 폴더를 선택하고 저장합니다.
5. Pages가 안내하는 주소에서 사이트를 확인합니다.

## 일정 업데이트

`index.html`의 `events` 배열에 일정을 추가하거나 수정합니다. `status`는 공식 발표일이면 `확정`, 시장 예상일이면 `예상`으로 설정하고, 각 일정에 해당하는 출처 URL을 넣습니다. 예상 일정은 공식 공지가 나오면 실제 날짜와 공식 출처로 바꿔 주세요.

현재 등록된 2026년 1~3분기 일정은 기업 공식 자료에 따른 실제 발표일이며, 2027년 1월 일정은 공개된 시장 예상치입니다.
